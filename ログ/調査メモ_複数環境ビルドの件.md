# 複数環境ビルドの調査メモ

## 目的

macOS と Windows の配布物を壊さずに組み立てる方法を確かめる。

## 調査結果

この構成では、異なる環境の SCons を同時に動かすと `src/*.os` を同じ場所へ出力し、形式の異なる中間ファイルが混ざる。実際に macOS のリンクで Windows 形式、Windows のリンクで macOS 形式を読んで失敗した。

SCons の公式資料は、複数構成を同時に扱う場合は構成ごとに出力先を分ける `variant_dir` を案内している。

- [Separating Source and Build Trees: Variant Directories](https://scons.org/doc/latest/HTML/scons-user/ch15.html)

現在の構成は中間ファイルを分離していないため、配布用ビルドは macOS debug、macOS release、Windows debug、Windows release の順で一つずつ実行する。
