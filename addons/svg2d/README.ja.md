# SVG2D

[English](README.md) | **日本語**

SVG2D は、SVGをGodotの中で描き、そのまま2D・3Dシーンへ使うためのアドオンだよ。上部の **SVG** 画面で標準SVGファイルを開いて保存できるよ。実行時は画面上の描画領域に合わせて画像を使い回し、`SVG3D` は投影寸法の1.5倍以上で画像化してミップマップも作るよ。

## 対応環境

- Godot 4.7 以降
- Windows x86_64
- macOS Universal

配布ファイルには、Windows x86_64 と macOS Universal のデバッグ用・配布用バイナリーが入っているよ。

## 導入しよう

1. `svg2d` フォルダーを自分のプロジェクトの `addons` フォルダーへコピーしよう。
2. Godot の「プロジェクト」→「プロジェクト設定」→「プラグイン」を開こう。
3. **SVG2D** を有効にしよう。

## 使ってみよう

2Dシーンでは `SVG2D`、3Dシーンでは `SVG3D` ノードを追加し、インスペクターの `src` にある **Open SVG…** から `.svg` 素材を選ぼう。選んだ絵と寸法もその場でプレビューできるよ。SVG文書の幅と高さが自然な寸法になり、2D・3D編集画面では不透明な絵をクリックしてノードをドラッグできるよ。画面上の寸法は `SVG2D` の変形やカメラで変えよう。`SVG3D` の空間内での寸法は `pixel_size` で調整しよう。

Inspectorの **Create Hitbox** では、Godot標準の `StaticBody` + Collision子ノード構成を自動生成できるよ。**Rect** は矩形を作り、**Shape** は透明な穴を除いたSVGの外周から2Dポリゴンまたは薄い3D形状を作るよ。

```gdscript
var picture := SVG2D.new()
picture.src = "res://picture.svg"
picture.scale = Vector2(2, 2)
add_child(picture)
```

## SVGを編集しよう

Godot上部の **SVG** を選び、SVGファイルを開くか、新しい文書を作ろう。よく使うベクター編集画面と同じく、左に道具、中央に作図面、右にパーツと見た目を置いているよ。

- 左の細い道具列から移動、点、ペン、鉛筆、四角、楕円、線、文字、表示移動を選ぼう。選んだ道具は緑になるよ。
- 中央の白い紙で描画と選択をしよう。定規、入切できる格子、緑の選択枠で、文書と周囲の作業台を見分けられるよ。
- 上から塗り、線、線幅、スナップ、表示倍率を調整しよう。ファイル操作とは帯を分けているよ。
- Layersでパーツとグループ、Transformで寸法と見た目、Historyで操作履歴を扱おう。SVGではXMLを直接編集できるよ。
- シーンの `SVG2D` または `SVG3D` を選ぶと、その `src` を同じ画面で編集できるよ。

未知のSVG要素や属性も、開いて保存するときに文書へ残すよ。複雑なベジェ曲線、パスの論理演算、文字組み、グラデーション、マスク、フィルター、シンボルはSVGタブで保持・編集できるけれど、専用の画面操作は未対応だよ。

`editor` フォルダー、プラグイン入口、編集用の説明は書き出し時に外れるよ。`src` 内の実行時コードは編集スクリプトを参照しないので、ゲームには描画部が分かれて入るよ。

アニメーションは初めはOFFだよ。`animation_enabled` をONにすると、`jitter_amount`（既定0.0008、最大0.3）を絵の縦横に対するぶれ率として使うよ。seed 1〜4で固定した4枚だけを作り、`animation_interval`（既定10フレーム）ごとに順番に切り替えるよ。OFFに戻すとアニメ用3枚のキャッシュも解放するよ。

2D・3Dとも `flip_h`、`flip_v`、`offset` を使えるよ。色と透明度は `modulate` で変えよう（2DではCanvasItem共通のVisibility欄、3DではAppearance欄）。

`adaptive` は初めから有効だよ。実行中のカメラだけでなく3Dエディターのカメラにも追従するよ。SVG文書の解像度に固定したいときは無効にしよう。この場合も各辺の上限は4096画素だよ。3Dは固定時も自然寸法の1.5倍で焼くよ。

自動解像度の画像は、RGBA画像1枚を64 MiB以内に収めるため、各辺を4096画素までにしているよ。画面上でとても大きくした場合は、この範囲で最も細かい画像を使うよ。

画素変換はx86_64ではSSE2、arm64ではNEONを使うよ。ほかのアーキテクチャー向けに組み立てた場合は、同じ結果になる通常のCPU処理へ切り替わるよ。

## 対応している SVG

四角、丸、パス、塗り、線、グラデーション、切り抜き、`use`、入れ子の `svg`、`viewBox`、基本的な CSS セレクターを描けるよ。

文字、フィルター、マスク、パターン、マーカー、SVG自身のSMILアニメーション、外部画像は編集時に保持するけれど、実行時ノードでは描画しないよ。
