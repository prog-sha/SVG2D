# SVG2D

[English](README.md) | **日本語**

SVG2D は、SVGをGodotの中で描き、そのまま2D・3Dシーンへ使うためのアドオンだよ。上部の **SVG** 画面で標準SVGファイルを開いて保存できるよ。実行時のGDExtensionは画面上の描画領域を整数画素で見て解像度を更新し、同じ画素数では作った画像を使い回すよ。`SVG3D` を同じ奥行きで左右へ移動し、投影寸法が変わらないときも画像を使い回すよ。

## 対応環境

- Godot 4.7 以降
- Windows x86_64
- macOS Universal

配布ファイルには、Windows x86_64 と macOS Universal のデバッグ用・配布用バイナリーが入っているよ。

## 導入しよう

1. `svg2d` フォルダーを自分のプロジェクトの `addons` フォルダーへコピーしよう。
2. Godot の「プロジェクト」→「プロジェクト設定」→「プラグイン」を開こう。
3. **SVG2D** を有効にしよう。

## 使ってみよう

2Dシーンでは `SVG2D`、3Dシーンでは `SVG3D` ノードを追加し、インスペクターから `src` に SVG の文字列を設定しよう。SVG文書の幅と高さが自然な寸法になるよ。画面上の寸法は `SVG2D` の変形やカメラで変えよう。`SVG3D` の空間内での寸法は `pixel_size` で調整しよう。

```gdscript
var picture := SVG2D.new()
picture.src = FileAccess.get_file_as_string("res://picture.svg")
picture.scale = Vector2(2, 2)
add_child(picture)
```

## SVGを編集しよう

Godot上部の **SVG** を選び、SVGファイルを開くか、新しい文書を作ろう。よく使うベクター編集画面と同じく、左に道具、中央に作図面、右にパーツと見た目を置いているよ。

- 左から移動、点、ペン、鉛筆、四角、楕円、線、文字、表示移動を選ぼう。
- 中央で描画と選択をしよう。選択をドラッグすると移動、右下のハンドルでは拡大縮小、点ツールでは直線パスと多角形の点を動かせるよ。
- Layersでパーツとグループを選ぼう。上部では履歴、複製、削除、グループ、重なり順、整列、表示倍率、保存を操作できるよ。
- AppearanceではID、寸法、塗り、線、不透明度、変形、文字を調整しよう。SVGタブではXMLを直接編集できるよ。
- シーンの `SVG2D` または `SVG3D` を選ぶと、その `src` を同じ画面で編集できるよ。

未知のSVG要素や属性も、開いて保存するときに文書へ残すよ。複雑なベジェ曲線、パスの論理演算、文字組み、グラデーション、マスク、フィルター、シンボルはSVGタブで保持・編集できるけれど、専用の画面操作は未対応だよ。

`editor` フォルダー、プラグイン入口、編集用の説明は書き出し時に外れるよ。`src` 内の実行時コードは編集スクリプトを参照しないので、ゲームには描画部が分かれて入るよ。

`adaptive` は初めから有効だよ。SVG文書の解像度に固定したいときは無効にしよう。この場合も各辺の上限は4096画素だよ。インスペクターでは `src`、`adaptive`、`pixel_size` にマウスを重ねると説明を読めるよ。

自動解像度の画像は、RGBA画像1枚を64 MiB以内に収めるため、各辺を4096画素までにしているよ。画面上でとても大きくした場合は、この範囲で最も細かい画像を使うよ。

画素変換はx86_64ではSSE2、arm64ではNEONを使うよ。ほかのアーキテクチャー向けに組み立てた場合は、同じ結果になる通常のCPU処理へ切り替わるよ。

## 対応している SVG

四角、丸、パス、塗り、線、グラデーション、切り抜き、`use`、入れ子の `svg`、`viewBox`、基本的な CSS セレクターを描けるよ。

文字、フィルター、マスク、パターン、マーカー、アニメーション、外部画像は編集時に保持するけれど、実行時ノードでは描画しないよ。
